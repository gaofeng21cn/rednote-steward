# Brand illustrations

The README uses `rednote-steward-overview-v2.png`, a raster illustration made
with the built-in imagegen tool. Its four-step workflow retains the original
overview's information structure. The lettering, ink strokes, pencil hatching
and notebook background follow the illustrated style of the owner's other
projects:

- [RedCube AI overview](https://github.com/gaofeng21cn/redcube-ai/blob/main/assets/branding/redcube-ai-overview-v3.png)
- [Med Auto Cast overview](https://github.com/gaofeng21cn/med-autocast/blob/main/assets/branding/medautocast-overview.en.png)

The complete generation brief is in
[`rednote-steward-overview-v2.prompt.md`](./rednote-steward-overview-v2.prompt.md).
The earlier vector overview is preserved in Git history at `v0.1.0`.

For future overview illustrations, provide the actual reference images to
imagegen and check the rendered text, workflow arrows and current product
capabilities before updating both README files. Keep the generated raster as
the published illustration and its prompt alongside it.
